**Where:** Inside the composer, the tabs above the editor

This is the single most useful thing to understand about the composer, and the
one people most often miss.

## The default: write once

When you create a post the composer opens on the **Global** tab. Whatever you
write there goes to every selected channel. One post, five platforms, one piece
of text.

For most posts this is all you need.

## Detaching one channel

Sometimes one platform needs different words: a hashtag block that suits
Instagram but not LinkedIn, a shorter version for X, a formal version for a
company page.

Switch to that channel's own tab. It starts locked, showing the global content,
with a prompt to:

> Click this button to exit global editing and customize the post for this
> channel

Click **Edit content** and that channel detaches. From then on:

- Editing the global text no longer changes this channel.
- Editing this channel no longer changes anything else.
- The channel tab shows it is in per-channel mode, with a control to go back.

Going back to global asks for confirmation, because the customised version is
discarded.

## What only works per-channel

**@mentions** are the notable one. They are only available on a detached
channel, because a handle only means something on one platform. Typing `@` in
the Global tab does nothing.

## When to detach and when not to

<Tabs>
  <Tab title="Stay global">
    - The same announcement everywhere
    - Content where platform differences are handled by settings rather than
      text, for example a YouTube title or a Reddit flair
    - Anything you will edit again later, since global edits stay in one place
  </Tab>
  <Tab title="Detach">
    - One platform needs a different length, and the character counter is
      complaining
    - You want to mention someone
    - Hashtag conventions differ between the platforms you selected
    - One platform gets a link and another strips links
  </Tab>
</Tabs>

## Editing an existing post

The Global tab only exists while you create a post. Click a post on the
calendar and the composer opens with every channel it was created for, each
with its own content, and the channel you clicked selected. Switch channels with
the tabs above the editor: what you change applies only to the channel you are
viewing, including its date.

The channel list is fixed while editing. To drop one channel, use
[Delete Post](/general/posts/actions-and-stats#deleting) and pick **Only from**
that channel.

Posts created with an older version of Postiz open with just the channel you
clicked.

## Sets are the shortcut

If you always detach the same channels in the same way, save the arrangement as
a [set](/general/settings/reusables) and load it when you start the next post.

## A caveat when building sets

While you are creating a set rather than a post, per-channel editing is
disabled:

> You can't edit networks when creating a set

Sets store the channel selection and settings, not detached per-channel copy.
