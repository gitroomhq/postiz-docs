**Where:** Settings, **Sets** and **Signatures**

<Note>
**Availability:** any paid Postiz Cloud plan. Self-hosted installs have both on
every install.
</Note>

Two small features that remove most of the repetitive work from the composer.

## Sets

A set is a saved channel selection with its settings. If you always post to the
same six channels configured the same way, a set restores that in one click
instead of rebuilding it every time.

### Creating one

Settings, **Sets**, then build the arrangement in the composer and **Save
Set**.

While you are building a set, per-channel content editing is disabled:

> You can't edit networks when creating a set

Sets store the channel selection and its settings, not the text. The text is
what changes every time.

### Using one

When you start a new post, Postiz offers your sets first. Pick one, or
**Continue without set**.

### What sets are good for

- One set per client, so their channels come up together.
- One set per content type, when a video post and a text post go to different
  places.
- One set for "everything", so a company announcement is one click.

## Signatures

A signature is a block of content appended to posts: a call to action, a
disclosure, a link to your newsletter.

### Creating one

Settings, **Signatures**, then write it. **Auto add signature?** decides
whether it is inserted into every new post automatically.

Only make one signature auto-add. It is inserted whenever a composer opens, so
two would both appear.

### Using one manually

The signature button in the composer toolbar inserts any saved signature at
the cursor. Useful when the sign-off depends on the post rather than always
applying.

### A caution

An auto-added signature goes into every new post on every channel, including
ones where it does not fit: a hashtag block on LinkedIn, a link on a channel
that strips links. If your signature is platform-specific, insert it manually
instead, or detach the channel and adjust. See
[Global vs per-channel](/general/composer/global-vs-per-channel).
