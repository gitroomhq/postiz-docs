## Settings Schema

When creating a post for Threads, use the following settings schema:

```json
{
  "settings": {
    "__type": "threads",
    "made_with_ai": false
  }
}
```

<Note>
Post content, images, and the schedule are configured at the post level - see
the [Create Post](/public-api/posts/create) reference.
</Note>

## Fields

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `__type` | `string` | Yes | Must be `threads` |
| `made_with_ai` | `boolean` | No | Label the post as AI-generated. Defaults to `false` |

### `made_with_ai`

When set to `true`, the post is disclosed as AI-generated and Threads shows its
**AI info** label on it. It applies to text, image, video and carousel posts,
and to every reply of a thread post. A carousel is labeled as a whole, not per
item.

Leaving it `false` does not stop Threads from adding the label by itself when
it detects AI-generated content.

## Complete Example

### Text Post

```json
{
  "type": "schedule",
  "date": "2024-12-14T10:00:00.000Z",
  "shortLink": false,
  "tags": [],
  "posts": [
    {
      "integration": {
        "id": "your-threads-integration-id"
      },
      "value": [
        {
          "content": "Hello from the Postiz API!",
          "image": []
        }
      ],
      "settings": {
        "__type": "threads"
      }
    }
  ]
}
```

### Thread Post

Create a thread by adding multiple items to the `value` array. Each entry
becomes a reply chained to the previous post:

```json
{
  "type": "schedule",
  "date": "2024-12-14T10:00:00.000Z",
  "shortLink": false,
  "tags": [],
  "posts": [
    {
      "integration": {
        "id": "your-threads-integration-id"
      },
      "value": [
        {
          "content": "1/ Starting a thread on Threads from the API",
          "image": []
        },
        {
          "content": "2/ Each value entry becomes a reply",
          "image": []
        }
      ],
      "settings": {
        "__type": "threads"
      }
    }
  ]
}
```

### Post with Image

```json
{
  "type": "now",
  "date": "2024-12-14T10:00:00.000Z",
  "shortLink": false,
  "tags": [],
  "posts": [
    {
      "integration": {
        "id": "your-threads-integration-id"
      },
      "value": [
        {
          "content": "Sharing today's launch screenshot",
          "image": [
            {
              "id": "image-id",
              "path": "https://uploads.postiz.com/launch.png"
            }
          ]
        }
      ],
      "settings": {
        "__type": "threads"
      }
    }
  ]
}
```
