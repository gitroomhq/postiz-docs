## Where to go

| What you have | Where to go |
|---|---|
| Something in the app is not working | [Discord](https://discord.postiz.com), the fastest route |
| A reproducible bug | [GitHub issues](https://github.com/gitroomhq/postiz-app/issues/new/choose) |
| A self-hosting problem | [Discord](https://discord.postiz.com), after checking [self-host troubleshooting](/troubleshooting/self-host) |
| A billing question or a refund | [Refunds and support](/cloud/refunds-and-support) |
| Anything involving account or payment details | The contact section on [postiz.com](https://postiz.com), not a public channel |

<Warning>
Never post API keys, OAuth secrets or payment details in Discord or in a GitHub
issue. Both are public.
</Warning>

<Note>
Self-hosted Postiz is supported by the community in their free time, on a
best-effort basis. Post your question and be patient, and include the detail
below so someone can actually help.
</Note>

## How to ask so you get an answer

Follow this order: **goal, environment, changes, results.**

### Goal

What were you trying to do?

- *I want to schedule a post to Reddit at 6pm*
- *I want to run Postiz in a container on a Raspberry Pi*
- *I want to use a custom domain*

### Environment

- Cloud, or self-hosted? If self-hosted, how did you install it and which
  version?
- Which browser and operating system?

### Changes

What changed just before it broke? An upgrade, a new browser, a config edit, a
plan change. "It used to work" is useful information, but "it used to work
until I upgraded to X" is far more useful.

### Results

What happened, and what did you expect? Quote the exact error text rather than
describing it, and include a screenshot where the interface is involved.

Error messages on failed posts come from the platform rather than from Postiz,
so the exact wording is usually the thing that identifies the problem.
